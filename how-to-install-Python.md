## Что мы устанавливаем и зачем

* **Python** — базовый язык программирования, на котором мы будем писать код.  
* **Miniconda** — минималистичный дистрибутив пакета Anaconda. Включает интерпретатор Python и систему управления пакетами и виртуальными окружениями `conda`. В отличие от полной Anaconda, Miniconda занимает минимум места на диске и позволяет установить только то, что действительно нужно.  
* **Библиотеки анализа данных** — специализированные модули:  
  * `pandas` и `openpyxl` — загрузка, обработка и анализ табличных данных (включая Excel);  
  * `numpy` и `scipy` — векторные вычисления, линейная алгебра и научные расчеты;  
  * `statsmodels` — статистическое моделирование и проверка гипотез;  
  * `matplotlib`, `seaborn` и `plotly` — визуализация и интерактивные графики;  
  * `scikit-learn` — базовые алгоритмы машинного обучения.  
* **Jupyter Lab** — интерактивная среда для запуска кода, оформления отчетов и визуализации данных прямо в браузере.

Полная установка занимает около 20–30 минут.

## Быстрый старт

> 💡 **У вас уже установлено окружение `courses`?**  
> Повторно ставить Miniconda не нужно:

> 1. Откройте терминал / Anaconda Prompt.  
> 2. Скачайте/обновите материалы курса ([Шаг 4](#шаг-4-загрузка-материалов-курса)).  
> 3. Активируйте окружение: `conda activate courses`  
> 4. Доустановите недостающие библиотеки: `conda install -c conda-forge numpy pandas scipy statsmodels scikit-learn openpyxl matplotlib seaborn plotly jupyter jupyterlab ipykernel`  
> 5. Запустите лабораторию: `jupyter lab`

## Пошаговая инструкция

### Шаг 1\. Установка Miniconda

Официальная документация и дистрибутивы доступны на сайте [docs.conda.io](https://docs.conda.io/projects/miniconda/en/latest/) и [anaconda.com](https://www.anaconda.com/docs/getting-started/miniconda/main).

Выберите один из двух способов установки:

#### Вариант А. Через графический установщик (рекомендуется для новичков)

1. Перейдите по ссылке: [anaconda.com/docs/getting-started/miniconda/main](https://www.anaconda.com/docs/getting-started/miniconda/main)  
2. Скачайте инсталлятор для вашей ОС:  
   * **Windows:** файл с расширением `.exe` (64-bit).  
   * **macOS:** файл с расширением `.pkg` (для чипов Apple M1/M2/M3/M4 выбирайте `arm64`, для старых Mac на процессорах Intel — `x86_64`).  
3. Запустите скачанный файл. **Все настройки оставляйте по умолчанию** — нажимайте «Далее» / «Next».

---

#### Вариант Б. Через командную строку (быстрее, без лишних окон)

**Инструкция для Windows (PowerShell)** Откройте PowerShell (`Win + R` → введите `powershell` → Enter) и выполните:

winget install \-e \--id Anaconda.Miniconda3

*Если команда `winget` не найдена, установите бесплатный пакет «Установщик приложений» (App Installer) из Microsoft Store.*  
После завершения закройте окно PowerShell.

**Инструкция для macOS** Откройте Терминал (`Cmd + Пробел` → введите `Терминал`) и выполните команды:

\# 1\. Скачиваем инсталлятор (для Apple Silicon / M-серия):

curl \-O https://repo.anaconda.com/miniconda/Miniconda3-latest-MacOSX-arm64.sh

&nbsp;

\# Примечание: если у вас старый Mac на процессоре Intel, замените arm64 на x86\_64

&nbsp;

\# 2\. Запускаем установку

bash Miniconda3-latest-MacOSX-arm64.sh

- Нажимайте `Enter` для прокрутки лицензии, введите `yes` для согласия.  
- Путь установки оставьте по умолчанию (`Enter`).  
- На вопрос *«Do you wish the installer to initialize Miniconda3?»* обязательно введите `yes`.  
- Закройте Терминал и откройте его заново.  
- Удалите установочный скрипт:  
  rm Miniconda3-latest-MacOSX-arm64.sh

**Инструкция для Linux** curl \-O https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86\_64.sh

bash Miniconda3-latest-Linux-x86\_64.sh

\# Следуйте инструкциям установщика, затем перезапустите терминал

rm Miniconda3-latest-Linux-x86\_64.sh

---

> ✅ **Проверка установки:**  
> Откройте командную строку/терминал и введите:

> conda \--version

> Если команда вернула версию (например, `conda 24.x.x`), всё установлено корректно.

### Шаг 2\. Запуск командной строки

Вся дальнейшая работа с пакетами происходит через командный интерфейс:

* **Windows:** откройте меню «Пуск» → найдите папку **Miniconda3** → запустите **Anaconda Prompt (Miniconda3)** или **Anaconda PowerShell Prompt**.  
* **macOS / Linux:** запустите стандартный **Терминал**.

В левой части строки перед приглашением ввода должна появиться метка `(base)`. Это означает, что Miniconda активна.

---

### Шаг 3\. Первичное обновление conda

Сразу после установки обновим саму conda и базовые утилиты:

conda update \--all

> ⚠️ Обратите внимание: перед словом `all` стоят **два** дефиса (`--`).

На запрос `Proceed ([y]/n)?` введите `y` и нажмите `Enter`. Дождитесь завершения операции.

### Шаг 4\. Загрузка материалов курса

Материалы, скрипты и наборы данных (`datasets`) расположены в репозитории:  
👉 [github.com/alexanderlata/data-analysis-python](https://github.com/alexanderlata/data-analysis-python)

Выберите удобный способ:

  *Перед каждым занятием обновляйте материалы командой `git pull` внутри этой папки.*

### Шаг 5\. Создание рабочего окружения `courses`

Работать напрямую в окружении `(base)` не рекомендуется. Мы создадим изолированное окружение с именем `courses`. Это делается **один раз**.

#### Вариант А. Автоматически из готового файла `environment.yml` (рекомендуется)

Если вы скачали репозиторий курса, перейдите в папку с проектом и создайте окружение по готовому списку:

\# Для Windows:

cd C:\\courses\\data-analysis-python

&nbsp;

\# Для macOS / Linux:

cd \~/courses/data-analysis-python

&nbsp;

\# Создание окружения:

conda env create \-f environment.yml

Команда автоматически загрузит нужную версию Python и весь необходимый стек библиотек. **Если вы выбрали этот вариант, шаг 7 можно пропустить.**

#### Вариант Б. Создание окружения вручную

Если файла конфигурации нет, создайте окружение вручную:

conda create \-n courses python=3.11

Подтвердите действие (`y` → `Enter`).

---

### Шаг 6\. Активация окружения

Для перехода в рабочее окружение введите:

conda activate courses

> ✅ **Проверка:** метка слева изменится с `(base)` на `(courses)`.  
> ⚠️ **Важно:** эту команду нужно выполнять **каждый раз** при открытии нового терминала перед началом работы.

---

### Шаг 7\. Установка библиотек

*(Пропустите этот шаг, если создавали окружение через `environment.yml` на шаге 5).*

Убедитесь, что активно окружение `(courses)`, и выполните установку пакетов из канала `conda-forge`:

conda install \-c conda-forge numpy pandas scipy statsmodels scikit-learn openpyxl matplotlib seaborn plotly jupyter jupyterlab ipykernel

Подтвердите установку вводом `y`.

---

### Шаг 8\. Подключение окружения к Jupyter

Зарегистрируйте окружение `courses` как ядро (kernel) для Jupyter:

python \-m ipykernel install \--user \--name=courses \--display-name "Python (courses)"

Теперь среда JupyterLab сможет запускать код именно в этом изолированном окружении.

---

### Шаг 9\. Запуск Jupyter Lab и проверка

1. Перейдите в папку с материалами курса:  
   \# Windows:  
   cd C:\\courses\\data-analysis-python  
   &nbsp;  
   \# macOS / Linux:  
   cd \~/courses/data-analysis-python  
2. Запустите Jupyter Lab:  
   jupyter lab  
3. В открывшемся браузере нажмите кнопку **«+»** и создайте новый Notebook, выбрав ядро **Python (courses)**.  
4. Вставьте в первую ячейку проверочный код и нажмите `Shift + Enter`:

import numpy, pandas, matplotlib, seaborn, plotly, scipy, statsmodels

&nbsp;

modules \= \[numpy, pandas, matplotlib, seaborn, plotly, scipy, statsmodels\]

for module in modules:

&nbsp;&nbsp;&nbsp;&nbsp;print(f"{module.\_\_name\_\_:12s} {module.\_\_version\_\_}")

&nbsp;

print("\\nВсё работает отлично\!")

Если версии библиотек напечатались без ошибок — среда полностью готова к работе.

> Для завершения работы Jupyter вернитесь в окно терминала и нажмите сочетание клавиш `Ctrl + C`, затем подтвердите выход (`y`).

## Частые проблемы и их решение

| Ситуация / Ошибка | Причина | Что делать |
| :---- | :---- | :---- |
| `conda: command not found` | Переменные окружения еще не применились | Перезапустите Anaconda Prompt или Терминал. На Windows используйте именно ярлык **Anaconda Prompt**. |
| `conda env create` пишет `prefix already exists` | Окружение `courses` уже создано ранее | Просто активируйте его: `conda activate courses`. |
| В начале строки написано `(base)`, а не `(courses)` | Окружение не активировано | Выполните `conda activate courses`. |
| В списке ядер Jupyter нет `Python (courses)` | Не зарегистрирован kernel | Выполните команду из [Шага 8](#шаг-8-подключение-окружения-к-jupyter). |
| `ModuleNotFoundError: No module named '...'` | Ноутбук запущен не в том ядре | В правом верхнем углу ноутбука кликните на ядро и выберите **Python (courses)**. |
| Ноутбук не находит файлы из папки `datasets` | Jupyter запущен не из корневой папки курса | Остановите сервер (`Ctrl+C`), выполните `cd` в папку курса и перезапустите `jupyter lab`. |
| Ошибка сети `CondaHTTPError` | Блокировка соединения или нестабильный интернет | Отключите корпоративный VPN / прокси и повторите команду. |

## Шпаргалка: команды на каждый день

Перед началом каждого занятия открывайте терминал и вводите:

\# 1\. Активировать рабочее окружение

conda activate courses

&nbsp;

\# 2\. Перейти в директорию материалов курса

cd C:\\courses\\data-analysis-python   \# Для Windows

\# cd \~/courses/data-analysis-python  \# Для macOS / Linux

&nbsp;

\# 3\. (Опционально) Подтянуть обновления материалов, если используете Git

git pull

&nbsp;

\# 4\. Запустить среду разработки

jupyter lab

Если преподаватель добавил новые библиотеки в `environment.yml`, обновите окружение одной командой:

conda env update \-n courses \-f environment.yml \--prune
